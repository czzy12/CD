- 框架无关 `AnalysisService`：复用正式解析管线与 `build_bankflow_result()`，默认 AI 关闭、外部网络禁用，来源级失败隔离为 `review`。
- `AnalysisTaskManager`：单任务后台执行、来源级进度、协作取消（running → cancelling → cancelled）、失败保护（不替换旧案件）、成功后原子接入 `CaseSession`。
- 来源预检：`CaseDirectoryRegistry` 使用 opaque handle，不向前端返回案件绝对路径；只接受 PDF/XLSX/XLSM 为正式输入。

- 保存：原生 SAVE 对话框、仅 JSON、禁止覆盖当前打开的标准结果文件。
- 桥接边界：稳定信封与错误码，不泄露 Python 堆栈、绝对路径、完整标准结果或完整原始交易。
