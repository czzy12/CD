## 2026-07-26 可追溯核实 MVP：确定性事实与待人工核实事项

### 背景与范围

- 已有 `schema_version: "1.0"` 的原始交易证据 JSON；本项只在其 `original_transactions` 基础上增加可复算事实和待人工核实事项，不解析新文字字段，不作风险判断或大模型结论。
- 事实和待核实事项均须引用已存在的稳定交易 ID，供下游在原始证据包中回溯。

### 实现

- `schema_version` 升至 `"1.1"`，在 `result.facts[]` 输出交易笔数、收入总额、支出总额、净额、交易期间和可用期初/期末余额；每项固定包含 `fact_type`、`value` 和 `evidence_transaction_ids`。
- `manual_review.items[]` 增加 `scope` 与 `evidence_transaction_ids`：交易范围项目保留原有交易/来源/页行证据，汇总范围项目引用触发余额缺失、余额不连续或收支余额不闭合的交易 ID。
- 不输出快进快出、对手集中度、风险标签或自然语言调查结论；未改银行解析器、通用 PDF、去重、统计口径或佛山农村商业银行第 23 页冻结项。

## 2026-07-03 GUI 月均利润测算

### 更新前问题

- 流水调整面板中的调整月份选择和 `固定分配` 控件占用空间，且和顶部日期筛选存在重复理解成本。
- 识别后只能看到流水月均收入，不能直接按利润率换算可支撑的月收入，也不能和拟开具月收入做即时比较。

### 解决方式

- `gui_v2.py` 中隐藏右侧流水调整面板的调整月份选择和 `固定分配` 控件。
- 调整期间改为跟随顶部筛选日期；顶部未启用日期筛选时，调整覆盖全部解析月份。
- 新增 `月均利润测算` 区域：
  - 手工输入开具月收入，单位为万元。
  - 手工输入利润率，单位为百分比数字，例如 `5` 表示 5%。
  - 根据当前流水月均收入计算 `利润率后月收入 = 流水月均收入 × 利润率`。
  - 当利润率后月收入低于开具月收入时，校验结果和生成金额标红提示。
- 利润率校验区改为紧凑行式展示，右侧面板增加滚动容器，避免窗口未最大化时文字被裁切。
- 顶部工具栏不再显示 `选择文件` 按钮，日期筛选文案改为 `筛选`，并去掉 `从/到` 标签。

### 验证结果

- `python -m py_compile gui_v2.py`：通过。
- 设置 `QT_QPA_PLATFORM=offscreen` 后实例化 `MainWindow`：通过。

### 影响范围

- 仅影响 GUI 展示和右侧面板计算提示。
- 不修改 PDF/Excel 解析器、交易明细、Excel 导出结构和收入佐证 JSON 结构。

## 2026-07-25 字段进度总账对账与口径防错

### 问题现象

- 在汇总“未完成文字字段确认与解析”时，直接把人工确认工作簿“来源盘点”中按整家银行或全部版式汇总的 `部分确认 / 部分实现` 计为待完成，错误得出 31 项待办。
- 该工作簿当前副本的标题、执行总览和多行状态仍停留在 2026-07-21 至 2026-07-23；而 `chg-20260722-01`、`chg-20260723-01`、`chg-20260724-02`、`chg-20260724-03` 已记录并提交了多个“已确认目标版式”的实现与字段专项验证。

### 原因

- 一个来源行可能覆盖多个版式；`部分确认` 表示其他版式仍未外推，不代表已经确认的目标版式未完成。
- 实现提交后，工作簿当前副本和执行总览没有同时刷新，缺少“工作簿状态 → 变更记录 → 当前提交”的对账门槛。

### 解决方式

- 更新当前人工确认工作簿：同步 24 个已完成来源状态，新增天津农村商业银行个人条目；来源/版式总账为 49 条，其中 42 条已实现、5 条部分实现或未实现、2 条暂缓（缺原件）。
- 规划目录只列真正待确认、待实现或缺真实样本验证的来源；已完成固定版式移出待办，同时保留同银行其他版式“部分确认”的边界说明。
- `PROJECT_STATUS.md` 更新当前实现提交 `03efcb8`、最新验证摘要和冻结项。

### 防错规则

1. 读取“来源盘点”前先确认该行的粒度是“固定目标版式”还是“整家银行/多版式汇总”。
2. 遇到 `部分确认 / 部分实现`，先检索晚于工作簿快照日期的 `chg-*`；只有确认目标版式没有实现记录时，才能列为文字字段待办。
3. 每批实现提交后，必须在同一轮更新工作簿标题日期、来源盘点三状态、执行总览、`PROJECT_STATUS.md` 和续接记录顶部快照；带日期的历史工作簿不回写。
4. 计划或报告不得把聚合来源行直接相加为“未完成字段数”；应按当前目标版式和真实样本验证状态统计。
