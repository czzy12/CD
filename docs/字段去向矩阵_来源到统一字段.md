# 来源 × 字段 → 统一字段去向矩阵

> 维护要求：新增或修改银行/版式解析器时，同步更新本矩阵；矩阵使用统一标准字段名，不按单个流水字段名另立口径。抽查/验收也按统一标准字段判断。

## 一、统一标准字段（口径）

| 统一字段 | 含义 | 参与 AI 经营判断 |
| --- | --- | --- |
| `counterparty_name` | 交易对手/商户名称（组织或已确认名称） | 是（仅企业/商户名称） |
| `summary` | 摘要 | 是 |
| `remark` | 备注 | 是（纯代码/订单号除外） |
| `purpose` | 用途 | 是 |
| `product_description` | 商品说明 | 是 |
| `merchant_name` | 商户名称（独立来源时使用） | 是 |
| `merchant_category` | 商户类别 | 是 |
| `transaction_method` | 交易方式/渠道 | 否（仅本地可追溯，不单独构成行业证据） |

统一字段只接受 `field_confidence == 1.0` 的可靠值；缺失或不可靠时保持为空，不回退全文扫描，不从混合文本猜测。

## 五、更新规则

1. 新增/修改解析器时，先在本矩阵补充“来源 → 统一字段 ← 原始表头”行。
2. 只允许映射到上表统一字段名；不新增平行字段名。
3. 新来源上线前至少运行一次字段级抽查（`tools/field_spot_check.py`），机械溯源必须为 0 未溯源，再交人工核对。
4. 本矩阵与 `INTEGRATION_CONTRACT.md`、`docs/流水事实指标字典_v1.md` 共同作为字段口径依据。
