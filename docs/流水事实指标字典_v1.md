# 流水事实指标字典 v1

> 版本：v1
> 建立日期：2026-07-26
> 适用接口：`bankflow_v2/result_export.py` 的版本化证据 JSON
> 基本边界：流水模块只输出可复算事实、确定性指标、可靠文字观察和证据引用，不输出代买、欺诈、人车不匹配、通过、拒绝等调查结论。

## 1. 分类与输出边界

| 类别 | 定义 | 标准结果位置 |
| --- | --- | --- |
| `numeric_indicator` | 只依赖 `original_transactions` 中标准数字字段的确定性计算 | 可进入 `result.facts[]` 或 `result.indicators[]` |
| `reliable_text_observation` | 只读取已拆列、非空且字段置信度满足规则的文字字段，报告命中和证据，不解释业务含义 | 后续独立 `observations[]`；当前不进入 `result.indicators[]` |
| `external_parameter` | 订单、案件、职业、地址、车型、首付、月供、关系等流水之外的信息 | 由下游以 `event` / `case_context` 提供；不写入流水原始结果 |
| `cross_check` | 将流水事实或观察与外部参数进行比对 | 由总项目或后续独立核实层执行；不进入当前 `result.indicators[]` |

共同规则：

- 数字指标只读 `original_transactions`，不读取调整层结果，不修改 `summary` 统计口径。
- 每项指标固定包含 `parameters`、`evidence_transaction_ids` 和 `field_coverage`。
- 缺少所需字段时输出 `available: false` 和原因，不从 `raw_text`、混合文本或 `generic_pdf` 猜字段。
- 文字观察只允许使用现有可靠标准字段；文字字段确认与解析恢复前保持暂缓。
- 外部审核动作只登记其所需事实和参数，不直接变成流水指标。

## 6. v1B 固定公式与边界

### `BF-N-005` 收入连续性

- 参与交易：非中性交易。
- 月份区间：首笔至末笔交易所在自然月，两个边界月都计入。
- 有收入月：该月存在至少一笔 `income != 0.00`。
- 最长连续收入月份：连续有收入月的最大长度；没有收入时为 0。
- 该指标描述数据期内收入月份分布，不等于工资稳定性、经营真实性或还款能力。

### `BF-N-006` 余额观察

- 余额覆盖：`balance is not None` 的交易。
- 快照：在每个 `source_file_id` 内，按自然日选择当天最后一笔有余额交易。
- 分布：最小值、中位数、算术平均值、最后快照、正余额快照笔数及占比。
- 不跨来源文件拼接余额链，不把事件快照均值称为日均余额，不将正余额比例解释为资金充足。

### `BF-N-007` 金额形态

- 参与交易：非中性且收入或支出非零的交易；金额取对应非零方向的绝对值。
- 固定单位：1 元、100 元、1000 元。
- 整齐命中：金额能被对应单位整除。
- 每个单位分别输出命中笔数和总参与笔数占比；该事实不等于流水包装。

### `BF-N-008` 收支规模与近期变化

- 月份区间：首笔至末笔交易所在自然月，缺交易月份补零。
- 全期间规模：收入、支出按期间月数计算月均值。
- 最近窗口：以末笔交易所在月为末月的 3 个自然月。
- 对比窗口：最近窗口之前的 3 个自然月。
- 连续月区间不足 6 个月时，近期比较 `available: false`；全期间规模仍可用。
- 两端月份可能不是完整自然月；结果只表示本次数据覆盖期内的数值变化，不等于业务趋势或风险结论。

## 7. v1C 本人账户转账候选边界

### `BF-N-009` 已确认本人账户精确匹配

- 外部输入：`verification_context.confirmed_owned_accounts[]`；每项必须具有完整账号、稳定账户引用、`verification_status: "confirmed"` 和归属证据引用。
- 可由 `case_accounts` 从文件抬头可靠元数据自动发现完整账号；文件夹只作案件边界，用户按 `account_ref` 一次确认角色后才生成外部输入。
- 参与交易：非中性、收入或支出非零、交易 ID 非空，且 `counterparty_account` 非空、完整、置信度为 1.0。
- 账号规范化：仅移除空白和连字符；规范化后必须为 12 至 32 位数字，再做完整精确匹配。
- 输出位置：独立 `result.observations[]`，不进入 `result.indicators[]`。
- 输出内容：候选交易方向、时间、金额、已确认账户引用、归属证据引用、证据交易 ID 和字段覆盖；不回显外部账户集合。
- 缺少有效账户集合时输出 `available: false` 和 `confirmed_owned_accounts_unavailable`；存在账户集合但可靠完整对手账号覆盖为 0 时输出 `available: false` 和 `reliable_counterparty_accounts_unavailable`，不得把零覆盖解释为无本人互转。
